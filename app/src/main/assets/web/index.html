Key 只存在电视里，不会回显到本页，也不会出现在任何日志或链接里。留空表示不修改已保存的 Key。

如何获得 Host 和 Key：到 console.qweather.com 注册并登录，创建一个项目，给项目添加「天气预报」这一项权限，创建一个 API KEY（仅勾选天气预报）。API Host 在「控制台 → 设置」（账号级）里，形如 abc1234.qweatherapi.com，详见 dev.qweather.com/docs/configuration/api-host/。把 Host 和 Key 分别填进上面两栏，再点「保存并立即更新」。

这里的 Key 不是你的账号密码，而是和风天气单独签发的一串密钥。它只保存在电视上；请不要把它写进代码、上传 GitHub，或截图发给别人。不配置这两项，主屏幕就不会显示天气。

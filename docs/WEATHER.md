# 天气（可选）

天气是 Aerial 桌面上的一个可选功能，不配置就完全不显示，也不影响其他任何功能。

## 这个功能做什么

- 在首页的大时间旁（图标版）或右上角胶囊内（大字版）显示一个天气图标和整数温度。
- 打开控制中心时，第一排最左会多出一个「天气」圆钮（图标 + 温度），选中它、按确认键，会跳到电视自带的小米天气应用（`com.xiaomi.tweather`）。
- 天气数据来自和风天气（QWeather）的新版 v1 接口。

## 怎么自己配置（自助）

1. 打开 <https://console.qweather.com>，注册并登录一个和风天气账号。
2. 创建一个「项目」，给这个项目添加 **天气预报** 这一项权限即可（不需要别的权限）。
3. 在该项目下创建一个 **API KEY**，创建时只勾选天气预报。
4. 在「控制台 → 设置」（账号级，不是某个项目里）找到 **API Host**，它形如 `abc1234.qweatherapi.com`（每个账号都不一样的域名）。官方说明见 <https://dev.qweather.com/docs/configuration/api-host/>。
5. 回到电视：打开壁纸的手机扫码设置页（和上传照片是同一个入口），在「天气（可选）」卡片里，把 API Host 和 API Key 分别填进对应栏，填好手动位置（可选），点「保存并立即更新」。

配置完成后，电视会尽快拉取一次天气并开始显示。

## 关于 Key 的几个要点

- 这里填的 **API Key 不是你的账号密码**，而是和风天气单独签发的一串密钥。
- Key 只保存在电视本机的应用私有存储里，**不会**回显到手机页面，**不会**写进任何日志或链接，也不会随备份离开电视。
- 请不要把 Key 写进代码、上传到 GitHub，或截图发给别人。泄露后到和风后台把它作废、重新创建一个即可。
- 手机页面上的 Key 输入框留空表示「不修改已保存的 Key」；要删除已保存的 Key，点「清除已保存的 Key」按钮。
- 不配置 Host 和 Key，主屏幕就不会显示天气，也不会有任何占位、报错或网络请求。

## 位置从哪里来

1. 优先读电视系统设置里的坐标（`mitv_user_location`，其次 `mitv_location`），校验有效后直接使用，不需要任何权限。
2. 电视没有有效坐标时，用手机页面里手动填的位置（填写 `纬度,经度`，如 `39.90,116.40`）。
3. 没有查询通道把「城市名」转成坐标：手动位置需要填写坐标，不能只填城市名。不会硬编码任何默认地址。

## 请求频率与限制

- 每小时最多请求 1 次，无论什么触发（启动、唤醒、切换风格、网络恢复、手动刷新、前台周期检查都一样）；失败也占这一小时，不会连续重试。
- 每个自然月最多请求 5 万次，在请求发出前就落盘计数。
- 每小时的那一次机会由「亮屏前台」的周期检查触发，电视待机时不会为了天气而唤醒。
- 以上都是**本机**计数：不约束同账号下其他设备，卸载或清除应用数据后不保证保留。账号侧的真实额度以和风后台为准。

## 显示规则

- 只有「开关已打开 + Host/Key 都已填 + 已拉到过一次数据」三者同时成立，主屏幕和控制中心才会显示天气。
- 关闭天气开关、清除 Key、或清空 Host，天气标记会**立即**从首页、胶囊和控制中心消失，包括上一次的旧缓存，也不会再发请求。
- 数据超过 3 小时未刷新会标为「已过期」，温度数字变淡，但不会把旧值冒充成最新值。

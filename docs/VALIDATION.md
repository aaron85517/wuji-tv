## 已知限制

- 固件可能忽略第三方默认 HOME 设置；当前依靠窗口事件恢复桌面，主页切换可能闪过系统桌面。
- 其他应用内空闲可能仍出现小米原生屏保。
- 航拍、每日精选依赖网络；网络可用性随地区和服务状态变化。
- 手机设置页是局域网 HTTP 与随机令牌保护，不应映射到公网。
- 暂无稳定 60fps 的性能承诺；部分较早导航采样存在错过帧期限的情况。
- 当前 APK 名称和部分界面仍使用 Aerial；wuji-tv 是此定制仓库的名称，保留包名以维持已有安装的数据和签名兼容。
- 上游 docs/HANDOFF.md、docs/ARCHITECTURE.md、docs/devices/ 是技术参考，包含旧按键实现和原版包名；使用本分支时优先读本说明与 README。
